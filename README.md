# Assignment 3 — TinyML Cosine Wave Predictor

SWAPD 453 · IoT Applications Development · Spring 2026

Train a small neural network to approximate `y = cos(x)` for `x ∈ [0, 2π]`, fully quantize it to int8, and run inference on an ESP32 with live Serial Plotter output.

## Project layout


## Python setup

- **Python:** 3.10 or newer  
- **TensorFlow:** 2.15.x (see `requirements.txt`)

```bash
cd A3_IOT
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # macOS / Linux
pip install -r requirements.txt
python train_cosine.py
```

This trains for 200 epochs, writes both `.tflite` files, `model.h`, and PNGs under `plots/`.

## Arduino IDE setup (ESP32)

1. Install [Arduino IDE 2.x](https://www.arduino.cc/en/software).
2. **Boards Manager:** install **esp32** by **Espressif Systems** (e.g. 3.0.x).
3. **Library Manager:** install one of:
   - **Chirale_TensorFlowLite** (recommended), or  
   - **TensorFlowLite_ESP32** (tanakamasayuki)
4. Copy `model.h` into `cosine_predictor/` (same folder as `cosine_predictor.ino`).
5. Open `cosine_predictor/cosine_predictor.ino`.
6. **Tools → Board:** your ESP32 DevKit (e.g. *ESP32 Dev Module*).
7. **Tools → Port:** your USB serial port (data-capable cable).
8. Upload. Open **Tools → Serial Plotter** at **115200** baud.

You should see two traces (predicted vs actual) tracking the cosine wave over at least two periods.

### Tensor arena

Default arena size is **4096 bytes** in the sketch. If inference succeeds, try **3072** or **2048** and note the smallest value that still runs; report `arena_used_bytes()` from the Serial Monitor at startup.
